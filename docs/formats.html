About Workflow formats: GZIP, XZ, BZIP2, Brotli, LZIP, LZOP, and LRZIP compress individual files rather than bundle multiple items into one archive, so they are created through SnipZip’s Workflow Builder.

Split ZIP, 7Z, RAR, and numbered archive volumes are also recognized. Keep every part in the same folder and open the first archive file. Support for a particular archive can vary when it uses an uncommon or unsupported codec.
