Release history

SnipZip release notes

Highlights and improvements in each App Store release.

Public release highlights, organized by version.

1.3

  • Safer extraction: Preserve macOS quarantine information when extracting downloaded archives.
  • Drag files out of archives: Export selected files and folders directly from the archive browser.
  • Edit ZIP archives: Add or remove files in a ZIP and save your changes as a new archive.
  • Browse folders in Quick Look: Browse folders as well as archives, without opening SnipZip.
  • Browse large archives faster: Faster archive browsing and extraction for large collections.
  • Finder password prompts: Extract password-protected archives from Finder without opening SnipZip; enter or retry the password when prompted.
  • Updated LZMA SDK: Updated the LZMA SDK to version 26.04.
  • UI improvements and bug fixes: Refined settings and archive browsing, with fixes across extraction, previews, and archive handling.

1.2.2

  • Shortcuts and workflows: Fixed chained archive actions and improved workflow/file-association handling.
  • Finder extraction: Fixed Extract Here and selective-extraction password retries.
  • Compatibility and previews: Improved damaged-archive handling and Quick Look, with macOS 27 updates and libarchive 3.8.9.
  • Other improvements and bug fixes.

1.2.1

  • Quick Look polish: Refined archive rows and nested-archive Pro messaging.
  • Finder fixes: Improved macOS 27 toolbar interactions and compression destinations.

1.2

  • Quick Look refinements: Improved archive previews and handling of damaged or truncated archives.
  • Updated compatibility: Added macOS 27 fixes and updated libarchive to 3.8.9.

1.1

  • Quick Look archive browsing: Browse files, folders, and folder sizes in Finder.
  • Nested archives: Pro users can browse supported archives inside other archives.
  • Improved reliability: Added compatibility and preview-safety improvements.

1.0.1

  • Improved compatibility: Updated archive components for better reliability.
  • More help in the app: Added Help and Contact Support links.

1.0 Initial release

  • Archive essentials: Create, browse, preview, and extract archives, including password-protected and split archives.
  • Finder integration: Compress and extract archives directly from Finder.
  • Automation: Run archive actions from Shortcuts, the command line, and reusable workflows.
